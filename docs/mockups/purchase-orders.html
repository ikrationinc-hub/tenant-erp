Design notes

What changed, and why

Same screen, same data, same tokens (IBM Plex Sans/Mono, steel-cobalt, the slate scale) — the changes below are about making the state of the list legible at a glance rather than introducing a new look.

  • Status, once Before, a coloured rail and a bold label said the same thing twice. Now it's one pill per row, coloured from the same status palette as the strip above — one system instead of two competing cues.
  • See the mix before you filter A strip above the filters shows live counts per status. Knowing how many orders are still in Draft no longer means scanning the table or opening the Status dropdown.
  • Filters you can actually see Empty filter inputs were a pale border on white, almost invisible against the bar. A soft fill now gives every control a visible edge at rest, and placeholder text moved to a readable slate.
  • Rows you can click, not just read The whole row is now the target, not only the small "Open" text — with a hover fill and the PO number tinting on hover to confirm it's live. The link itself stays, for keyboard and screen-reader users.
  • Numbers that line up PO numbers, dates and invoice references sit in the same monospace already used for the column headers, with tabular figures, so a column of numbers reads as a column.
  • A touch more air Row padding grew from a cramped 6px to 10px. Nothing else about the density changed — but a table meant to be stared at for hours earns a little more room per line.
